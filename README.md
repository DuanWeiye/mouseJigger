# MouseJigger — ESP32 蓝牙鼠标随机移动器（带 WiFi 配置页）

基于 **ESP32** 的低功耗蓝牙（BLE）鼠标模拟器：定时随机微移鼠标几个像素，
让电脑误以为有人在操作，从而**防止进入休眠/锁屏/离开状态**。

设备会被电脑识别为一个普通的蓝牙鼠标（默认名称 `RAPOO BT MOUSE`），无需安装任何驱动或软件。
除蓝牙功能外，还内置 **WiFi 配置网页**，可在手机/电脑上设置设备名、移动间隔与幅度、
按工作日/周末排定的**移动时段周计划**，并在接入 [M5Stack Unit ENV](https://docs.m5stack.com/en/unit/env)
时显示**温湿度**。

> ✅ **默认目标型号：[M5Stack ATOM Lite](https://docs.m5stack.com/zh_CN/core/ATOM%20Lite)**
> 固件引脚配置完全对应 ATOM Lite，**开箱即烧、无需改动**。
> 使用其它 ESP32 开发板时，请参考下文「[换用其它 ESP32 开发板](#️-换用其它-esp32-开发板需自行修改)」自行调整。

---

## ✨ 特性

- 🖱️ **真·硬件鼠标**：以标准 BLE HID 鼠标身份连接，系统无法区分真假。
- 🎲 **随机抖动**：可设间隔（默认 5～8 分钟）随机移动可设幅度（默认 2～5 像素），X/Y 方向随机。
- 📶 **WiFi 配置页**：首次开机自建热点 + 强制门户引导配网；联网后用网页随时调参。
- 🗓️ **周计划**：按「工作日 / 周末」两行、每半小时一格，设定允许移动的时段（需联网取时间）。
- 🌡️ **温湿度**：自动检测 M5 Unit ENV（SHT30/SHT40/DHT12），网页每分钟刷新显示。
- 💡 **RGB 状态灯**：板载 WS2812 指示蓝牙配对/连接/暂停状态。
- 🔋 **省电设计**：CPU 降频至 80MHz，LED 低亮度。
- 🪶 **轻量蓝牙栈**：使用 **NimBLE**，为 WiFi/Web 共存腾出充足内存。
- 🔘 **一键重置**：长按按键 5 秒清除蓝牙配对与 WiFi 设置。

## 🧰 硬件需求

### 默认硬件：M5Stack ATOM Lite（开箱即用）

[M5Stack ATOM Lite](https://docs.m5stack.com/zh_CN/core/ATOM%20Lite) 主控为 ESP32-PICO-D4，
自带本固件所需的全部外设，**无需额外接线**：

- 1 颗板载 WS2812C RGB LED（GPIO27）
- 1 个正面按键（GPIO39，板载已带上拉，可直接读取）

可选外接 **M5Stack Unit ENV 温湿度传感器**（Grove 口即插即用，自动识别）。

### 引脚分配（ATOM Lite 默认）

| 功能 | GPIO | 备注 |
|---|---|---|
| WS2812 LED 数据 | `27` | 板载 RGB LED |
| 按键 | `39` | 正面按键（板载已带上拉） |
| Unit ENV I2C（SDA / SCL） | `26` / `32` | Grove 口，可选 |

### ⚠️ 换用其它 ESP32 开发板需自行修改

若你用的不是 ATOM Lite，请按实际硬件修改 `mouseJigger.ino` 顶部的 `LED_PIN` / `BUTTON_PIN`，
以及 `env.h` 顶部的 `MJ_I2C_SDA` / `MJ_I2C_SCL`，并注意：

- **按键引脚**：本固件按「按下 = 低电平」读取。GPIO34～39 是输入专用脚、**无内部上拉**。
  - 若按键接在 34～39 且无板载上拉，需外接上拉电阻（10kΩ 到 3.3V，另一端接 GND）；
  - 或改接到普通 GPIO（如 25/26/33），并把 `pinMode(BUTTON_PIN, INPUT)` 改为 `INPUT_PULLUP`。
- **LED**：若无 WS2812，需另接或修改 `FastLED.addLeds<...>` 的芯片/颜色顺序。
- **build.sh**：里面的 `ATOM_DEV`（烧录目标的 by-id 路径）写死为作者的设备，clone 后请改成你自己的。

## 💡 LED 状态指示

| 颜色 | 状态 | 含义 |
|---|---|---|
| 🔵 蓝灯慢闪 | 未配对 | 等待电脑发现并配对蓝牙 |
| 🔵 蓝灯常亮 | 已配对，未连接 | 曾配对过，但当前未连上 |
| 🟢 绿灯常亮 | 已连接，工作中 | 正在按计划随机移动鼠标 |
| 🟡 黄灯常亮 | 已连接，计划暂停 | 当前处于周计划「不允许移动」时段 |
| 🔴 红灯约 1 秒 | 重置 | 长按 5 秒清除配对+WiFi 后重启 |

> WiFi 当前状态（AP / 已联网 / IP）在配置网页里查看。

## 📶 配网与使用

### 首次配网（AP 强制门户）

1. 设备首次开机会自建一个**无密码热点 `MouseJigger`**。
2. 手机/电脑连接该热点，系统通常会自动弹出「登录网络」页面；
   若未弹出，浏览器访问 **`http://192.168.4.1/`**。
3. 在「WiFi」区点**扫描**，选择你的路由器、输入密码、点**连接此 WiFi**。
4. 连接成功后，设备记住该网络，下次开机自动联网。

### 联网后访问

设备联网后会启用 mDNS，可直接访问 **`http://mousejigger.local/`**
（部分 Windows 需安装 Bonjour；不行就用路由器后台查到设备 IP 访问）。
页面与配网时一致，可随时改 WiFi、调参，或**重置 WiFi**。

### 配置项

- **蓝牙设备名**：修改后设备会自动重启使其生效。
- **移动间隔（秒）**：随机移动的最短/最长间隔。
- **移动幅度（像素）**：随机移动的最小/最大像素。
- **周计划**：两行格子（工作日 周一~五 / 周末 周六日），每格 30 分钟，
  勾选=该时段**允许移动**。**需联网取得时间后才生效；未联网时始终允许移动。**
- **温湿度**：接入 Unit ENV 时自动显示，每分钟刷新；未接入则隐藏。
- **保存设置 / 恢复默认**：恢复默认不影响已保存的 WiFi。

### 重置

- **网页**：点「重置 WiFi」清除 WiFi 并重启回到配网热点。
- **长按按键 5 秒**：同时清除**蓝牙配对**与**WiFi 设置**并重启。

## 📦 软件依赖

| 依赖 | 用途 | 安装 |
|---|---|---|
| Arduino-ESP32 核心（M5Stack 版） | ESP32 / ATOM Lite 板支持 | 开发板管理器 |
| [NimBLE-Arduino](https://github.com/h2zero/NimBLE-Arduino) | 蓝牙 HID 鼠标 | 库管理器 |
| [FastLED](https://github.com/FastLED/FastLED) | 驱动 WS2812 | 库管理器 |

> WiFi、Web 服务器、DNS、mDNS、NVS、NTP、I2C 等均使用 ESP32 核心自带库，无需额外安装。
> 温湿度为直接读取传感器，**不依赖 M5Unit-ENV 库**。

### Arduino IDE 安装步骤

1. **安装 ESP32 开发板支持**
   `文件 → 首选项 → 附加开发板管理器网址` 填入 M5Stack 板源（参考 M5Stack 文档），
   然后在 `工具 → 开发板 → 开发板管理器` 搜索安装 **M5Stack**（含 ESP32）。
2. **安装库**：`工具 → 管理库`，分别搜索并安装：
   - **NimBLE-Arduino**（作者 h2zero）
   - **FastLED**
3. **选择开发板**：`工具 → 开发板 → M5Stack` 中选择 **M5Atom / M5Stack-ATOM**。
4. 打开 `mouseJigger.ino`，选择串口，点上传。

## 🚀 用脚本编译 / 烧录（可选）

仓库提供 `build.sh`（基于 Arduino 1.8.19 命令行 + esptool）：

```bash
./build.sh        # 仅编译，产物 mouseJigger.bin
./build.sh -f     # 编译并烧录到 ATOM Lite
./build.sh -w     # 仅烧录已编译的 mouseJigger.bin（不重新编译）
```

- 烧录目标设备写死为 `build.sh` 里的 `ATOM_DEV`（by-id 路径，避免误刷其它板子），
  **clone 后请改成你自己的设备**（`ls /dev/serial/by-id/`）。
- 默认烧录波特率 `115200`（稳）。若你的板子 USB 串口稳定，可提速：
  `BAUD=921600 ./build.sh -f`。

## ⚙️ 源码结构

| 文件 | 说明 |
|---|---|
| `mouseJigger.ino` | 主程序：状态机、按键、LED、移动逻辑 |
| `nimble_mouse.h` | 基于 NimBLE 的轻量 HID 鼠标 |

| `net.h` | WiFi/AP/门户/mDNS/NTP/周计划 |
| `web.h` | Web 服务器与配置页面（内嵌 HTML） |
| `env.h` | Unit ENV 温湿度自动检测与读取 |
| `build.sh` | 编译/烧录脚本 |
